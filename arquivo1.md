# Explorando o Markdown

Este arquivo apresenta recursos básicos da linguagem **Markdown**.

## 1. Ênfase no texto

Use *itálico*, **negrito** ou ~~texto riscado~~ para formatar palavras.

## 3. Links

Consulte a documentação em [Markdown
Guide](https://www.markdownguide.org/).

## 4. Imagens

A sintaxe para inserir uma imagem é:

``` markdown
![Descrição da imagem](imagens/exemplo.png)
```
